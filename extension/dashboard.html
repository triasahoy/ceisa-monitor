    Dukung proyek ini

    Selamat datang di CEISA Monitor

    Pantau status dokumen CEISA 4.0 perusahaan Anda dalam satu layar. Empat langkah untuk memulai:

    1. Masuk ke portal CEISA 4.0 seperti biasa dengan akun Anda sendiri.
    2. Buka halaman Daftar Dokumen portal.beacukai.go.id/dokumen-pabean/ dan tunggu sampai tabel dokumen tampil. Tombol CEISA Monitor akan muncul di pojok kanan bawah portal.
    3. Kembali ke dasbor ini, lalu klik Perbarui data. Ekstensi membaca daftar dokumen dari sesi login Anda. Penarikan pertama memerlukan 1 sampai 3 menit. Biarkan tab portal tetap terbuka.
    4. Atur Profil perusahaan: jenis fasilitas, status final, dan target SLA.

    Data diolah dan disimpan hanya di peramban ini. Ekstensi tidak menyimpan kata sandi atau token, tidak mengirim data ke server, dan hanya membaca data. Ekstensi ini tidak resmi dan tidak berafiliasi dengan Direktorat Jenderal Bea dan Cukai.

    Ingin melihat hasilnya terlebih dahulu tanpa masuk ke portal? Coba mode demo dengan data contoh.
