Kebijakan Privasi CEISA Monitor

Berlaku sejak 28 September 2026 · Versi 1.3.0 dan seterusnya

CEISA Monitor adalah ekstensi Chrome tidak resmi untuk memantau status dokumen pabean di portal CEISA 4.0. Ekstensi ini tidak berafiliasi dengan, tidak disetujui oleh, dan tidak dibuat oleh Direktorat Jenderal Bea dan Cukai.

Data yang dibaca

Ketika pengguna menekan Perbarui data atau mengaktifkan pembaruan otomatis, ekstensi membaca daftar dokumen pabean yang dapat diakses pengguna di portal CEISA 4.0 (portal.beacukai.go.id): nomor pengajuan, nomor dan tanggal pendaftaran, jenis dokumen, status proses, jalur, respons, kantor pabean, dan nama perusahaan. Ekstensi juga membaca nama pengguna serta nomor identitas perusahaan (NPWP/NITKU) dari sesi login, semata-mata untuk memisahkan data antarakun.

Token sesi dibaca dari tab portal hanya pada saat penarikan data, dipakai untuk permintaan baca tersebut, lalu dibuang. Ekstensi tidak membaca atau menyimpan kata sandi, tidak menyimpan token, tidak memperpanjang sesi, dan tidak mengubah data apa pun di CEISA.

Tempat data disimpan

Hasil olahan, rekaman status harian (paling lama 62 hari), pengaturan, pilihan bahasa, profil perusahaan, dan catatan tindak lanjut disimpan di chrome.storage.local pada komputer pengguna, terpisah per akun. Data tidak dikirim ke server pengembang atau pihak mana pun. Ekstensi tidak memakai analitik, iklan, pelacakan, atau layanan pihak ketiga, dan tidak menjual atau mengalihkan data pengguna. Tautan “Dukung proyek ini” hanya membuka halaman Saweria (saweria.co) di tab baru bila diklik; ekstensi tidak mengirim data apa pun ke Saweria. Fitur penugasan menyusun pesan tugas di peramban; pesan hanya disalin atau dibuka di WhatsApp (wa.me) bila pengguna mengklik tombolnya, dan dikirim oleh pengguna sendiri. Nomor WhatsApp penanggung jawab, riwayat tindak lanjut, dan templat tugas disimpan lokal di komputer pengguna. Berkas ekspor tindak lanjut (.json) hanya dibuat bila pengguna mengkliknya.

Berkas yang diekspor (Excel, CSV, presentasi, laporan) dibuat di peramban dan disimpan ke folder unduhan pengguna. Pembagian berkas tersebut sepenuhnya berada di bawah kendali pengguna.

Menghapus data

Buka Pengaturan di dasbor, lalu pilih Hapus data tersimpan. Menghapus ekstensi dari Chrome menghapus seluruh data yang tersimpan.

CEISA Monitor Privacy Policy

Effective 28 September 2026 · Version 1.3.0 and later

CEISA Monitor is an unofficial Chrome extension for tracking customs document status in the CEISA 4.0 portal. It is not affiliated with, endorsed by, or produced by the Directorate General of Customs and Excise of Indonesia (DJBC).

Data accessed

When the user clicks Refresh or enables automatic refresh, the extension reads the list of customs documents the user can already see in the CEISA 4.0 portal: submission number, registration number and date, document type, process status, inspection lane, response, customs office, and company name. It also reads the user's name and company tax ID (NPWP/NITKU) from the logged-in session, only to keep data from different accounts separate.

The session token is read from the portal tab only during a refresh, used for that read-only request, and discarded. The extension never reads or stores passwords, never stores tokens, never extends sessions, and never changes any data in CEISA.

Storage and sharing

Processed results, daily status records (kept for up to 62 days to show changes), settings, language choice, company profile, and follow-up notes are stored in chrome.storage.local on the user's computer, separated per account. No data is sent to the developer or any third party. The extension uses no analytics, advertising, tracking, or third-party services, and does not sell or transfer user data. The “Support this project” link only opens the Saweria page (saweria.co) in a new tab when clicked; the extension sends no data to Saweria. The task feature composes messages in the browser; a message is only copied or opened in WhatsApp (wa.me) when the user clicks the button, and the user sends it themselves. Owners' WhatsApp numbers, follow-up history, and task templates are stored locally on the user's computer. A follow-up export file (.json) is only created when the user clicks the button. Exported files are created in the browser and saved to the user's downloads folder.

Deleting data

Open Settings in the dashboard and choose Delete stored data, or remove the extension from Chrome to delete all stored data.
